# F1 Game

A browser-based Formula racing game designed around **timing, rhythm, precision, tactical decisions, and risk management**, rather than traditional direct steering/brake/throttle controls.

The game is intended to work well on both:
- mobile touch devices, including Samsung Galaxy S25 Ultra
- desktop browsers on Windows using keyboard input

## Project wiki

The repository wiki is the source of truth for gameplay and development specifications.

Start here: [wiki/README.md](wiki/README.md)

### Current design

The first defined gameplay pillar is **RaceFlow**, a control system where the player executes corners through timing windows, short input sequences, holds/releases, and tactical choices. Execution quality affects lap time, car behavior, tyre condition, component wear, damage risk, and racing outcomes.
